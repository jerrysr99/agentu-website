October 23, 2026

No vendor changed a token price on any model I track today. OpenAI's October 23 shutdown date for gpt-4.1-nano, o4-mini and gpt-image-1 has arrived, and Perplexity retires its routes to seven older OpenAI models at 7:00 PM CT tonight.

Friday, October 23, 2026 · Prices as of 8:45 AM CT

Executive Summary

No token price changed today on any model I track. Anthropic, OpenAI, Google, xAI, DeepSeek, Z.ai, MiniMax, Mistral, Alibaba, Meta, TypeSafe, Xiaomi, Tencent and StepFun show the same prices as Thursday. Alibaba updated its prices October 22, and every Qwen price I track matches, including Qwen3.8-27B at $0.50 input and $3.00 output per million tokens.

OpenAI gives October 23, 2026, today, as the shutdown date for gpt-4.1-nano, o4-mini and gpt-image-1, with no time of day (midnight UTC was 7:00 PM CT Thursday). Google's deep-research-pro-preview-12-2025 also reaches its shutdown date today, the day after gemini-omni-flash-preview and three Veo 3.1 previews reached theirs.

Perplexity retires its Agent API and Orchestrator API routes to seven older OpenAI model IDs (openai/gpt-5.4, gpt-5.4-mini, gpt-5.4-nano, gpt-5.2, gpt-5.1, gpt-5 and gpt-5-mini) at 7:00 PM CT today. It also renamed the Agent API's "preset" setting to "effort"; Perplexity says the models, limits and pricing stay the same and the old "preset" name is still accepted.

Anthropic launched Claude Models on Google Cloud (Anthropic managed): Anthropic's own Claude API, reached through a Google Cloud project, with Google Cloud IAM for access and Google Cloud Marketplace for billing. Fast mode for Claude Opus 5.5 is available there. Anthropic's own prices did not change. Meta now bills every SAM 3.1 video request for at least 50 frames.

Microsoft's Foundry retirement page filled in new dates: DeepSeek-V3.2 and DeepSeek-V3.2-Speciale retire November 1, 2027 (Microsoft names DeepSeek-V4.1-Flash and DeepSeek-V4-Pro as replacements), cohere-command-a February 15, 2027, embed-v-4-0 June 1, 2027, Cohere's rerank v4.0 models September 13, 2027, and gpt-oss-120b September 15, 2027. Kimi-K2.7-Code on Foundry moved from October 3, 2026 to April 16, 2027.

Prices from Amazon, ByteDance, IBM and Moonshot could not be confirmed today, so Kimi K3 is not re-listed; Microsoft lists no pay-as-you-go prices. The performance chart still uses scores from October 16.

What This Means for Customers

  • If anything still calls gpt-4.1-nano, o4-mini or gpt-image-1, today is OpenAI's listed shutdown date. OpenAI names gpt-5.6-luna, gpt-5.6-terra, and gpt-image-2.5-sunburst or gpt-image-2.5-flare as replacements.
  • If you route OpenAI models through Perplexity's Agent or Orchestrator API, update model selections and fallback chains before 7:00 PM CT today; after that the retired IDs are no longer accepted.
  • If you use Google's deep-research-pro-preview-12-2025, move to deep-research-preview-04-2026; Google's shutdown date is today, with no time of day.
  • If your company buys cloud through Google, Claude is now available as an Anthropic-operated service billed through Google Cloud Marketplace, with Opus 5.5 fast mode. Compare it with Anthropic's direct pricing before switching.
  • If you segment short video clips with Meta's SAM 3.1, budget at least 50 frames per request; shorter clips are billed as 50.
  • If you run DeepSeek-V3.2 or DeepSeek-V3.2-Speciale on Azure Foundry, you have until November 1, 2027. If you run cohere-command-a there, plan for February 15, 2027.
  • If your agents search the web through DeepSeek Harness, Claude Code or Codex, those server-side calls start billing at $0.75 per 1,000 successful Search or Fetch requests at 11:00 AM CT on Saturday, October 31. Track this separately from token spend.
  • Claude Haiku 4.5 is still active. Anthropic lists retirement not sooner than October 15, 2026, a date that has passed, and still sets no date. Keep a tested fallback ready.
